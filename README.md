# Experiment 3: 3D Multiplayer Object-Collection Game

A real-time multiplayer 3D object collection game built with Three.js, Node.js, Express, and Socket.IO.

## Features
- **3D Environment**: Cyberpunk arena rendered with Three.js, lighting, neon pillars, and dynamic shadows.
- **Authoritative Multiplayer**: Node.js and Socket.IO server prevents race conditions and duplicate point claims.
- **Collectible Glowing Orbs**: Pulsating, floating 3D objects that grant +10 points and respawn after 3 seconds.
- **Live Leaderboard**: Real-time player rankings with dynamic color tags and score tracking.
- **Minimap & Radar**: Top-down architectural radar showing all players and orbs in real time.
- **Procedural Sound**: Web Audio API sound synthesizer with zero external asset dependencies.
